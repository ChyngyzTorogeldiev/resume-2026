# Портфолио — Чингиз Торогелдиев

Одностраничный сайт-портфолио: тёмная и светлая темы, два языка (RU / EN),
живой анимированный фон, 3D-карточки, SEO-разметка для поисковиков.
Без сборщиков и зависимостей — чистые HTML, CSS и JavaScript.
Шрифт лежит в самом проекте: сайт не обращается ни к одному внешнему сервису.

---

## 1. Как запустить

Просто откройте `index.html` в браузере — всё заработает.

Для «честного» локального сервера (нужно, чтобы корректно читался `site.webmanifest`):

```bash
# любой из вариантов, из папки проекта
npx serve .
python -m http.server 5173
```

Затем откройте http://localhost:5173

## 2. Что править

**Весь текст сайта лежит в одном файле — [`js/data.js`](js/data.js).**
HTML, CSS и остальной JS трогать не нужно.

Данные уже заполнены по вашему резюме. Места, где нужен ваш взгляд, помечены
в файле меткой `← ПРОВЕРЬТЕ` (годы проектов, описание «Гренок», почта).

| Что | Где в `js/data.js` |
|---|---|
| Имя, должность, заголовок, текст о себе | `person` |
| Почта, телефон, Telegram, WhatsApp, GitHub, LinkedIn | `contacts` |
| Цифры на первом экране | `stats` |
| Технологии (бегущая строка и блок «Работаю с») | `stack` |
| Услуги | `services` |
| Проекты и фильтры к ним | `projects`, `projectFilters` |
| Этапы работы | `process` |
| Опыт и образование | `experience` |
| Вопросы и ответы | `faq` |
| Подписи кнопок и заголовки разделов | `ui` |

Мелочи:

* **Пустое поле не показывается.** Убрали `whatsapp` — кнопка исчезла.
* **Проект без ссылки** просто не показывает кнопку «Открыть проект».
  Появится публичный адрес — раскомментируйте строку `link:` в этом проекте.
* **Год проекта.** `year: ""` — год не отображается.
* **Заголовки с акцентом.** Слово в `*звёздочках*` выводится акцентным цветом:
  `"Пишу backend на *Python*"`.
* **Цвета обложки проекта** — поле `colors: ["#4a4fd6", "#7c5cff"]`.
* **Фото** — `person.avatar` (сейчас `assets/avatar.png`). Пустое значение —
  вместо фото будут инициалы на цветном фоне.
* **Резюме** — `person.resume` (сейчас `assets/cv.pdf`), кнопка на первом экране.

Фирменные цвета сайта — переменные `--a1`, `--a2`, `--a3` в самом верху
[`css/style.css`](css/style.css). Акцент (мятный) задаётся переменной `--a2`.
Шрифт — переменная `--font` там же.

## 3. Форма обратной связи

По умолчанию форма открывает почтовый клиент посетителя с уже заполненным письмом —
работает без сервера.

Чтобы письма приходили на почту напрямую, подключите бесплатный
[Formspree](https://formspree.io): в функции `initForm()` в [`js/app.js`](js/app.js)
замените блок отправки на:

```js
const res = await fetch("https://formspree.io/f/xxxxxxx", {
  method: "POST",
  headers: { Accept: "application/json" },
  body: fd
});
note.textContent = res.ok
  ? (lang === "ru" ? "Спасибо! Отвечу в ближайшее время." : "Thanks! I'll reply shortly.")
  : (lang === "ru" ? "Не отправилось — напишите на почту." : "Failed — please email me.");
if (res.ok) form.reset();
```

## 4. Публикация

**GitHub Pages**

```bash
git init && git add . && git commit -m "portfolio"
git branch -M main
git remote add origin https://github.com/ChyngyzTorogeldiev/portfolio.git
git push -u origin main
```
Затем в репозитории: *Settings → Pages → Source: main / root*.

**Netlify** — перетащите папку проекта в окно netlify.com/drop.

### После публикации

1. Впишите адрес сайта в `contacts.website` ([`js/data.js`](js/data.js)).
2. Замените `https://example.com` в [`robots.txt`](robots.txt) и [`sitemap.xml`](sitemap.xml).
3. При желании замените `assets/og.png` (1200×630) — эту картинку видят
   в Telegram, WhatsApp и соцсетях при отправке ссылки.
4. Добавьте сайт в [Google Search Console](https://search.google.com/search-console)
   и [Яндекс.Вебмастер](https://webmaster.yandex.ru).
5. Поставьте ссылку в профили GitHub, LinkedIn, Telegram и в резюме.

Микроразметка `schema.org/Person` (имя, должность, контакты, услуги, профили)
собирается автоматически из `data.js`.

## 5. Структура

```
index.html          разметка страницы
css/style.css       вёрстка, темы, анимации
js/data.js          ← ВСЁ СОДЕРЖИМОЕ (правится только этот файл)
js/app.js           рендер, язык, тема, меню, фильтры, форма
js/background.js    анимированный фон на canvas
assets/avatar.png   фото
assets/photo.png    фото без фона (запасное, если понадобится)
assets/cv.pdf       резюме
assets/favicon.svg  иконка вкладки
assets/og.png       превью для соцсетей
assets/fonts/       шрифт Onest (woff2) + текст лицензии OFL.txt
site.webmanifest    robots.txt   sitemap.xml
```

Анимации отключаются сами, если в системе включён режим «уменьшить движение».

## 6. Что здесь платное и чьё это всё

**Платного на сайте нет ничего.** Полный список того, из чего он собран:

| Что | Откуда | Лицензия | Деньги |
|---|---|---|---|
| HTML, CSS, JavaScript | написаны с нуля для вас | ваши | 0 |
| Шрифт **Onest** | `assets/fonts/`, взят с Google Fonts | SIL Open Font License 1.1 | 0 |
| Иконки (почта, телефон, услуги) | нарисованы прямо в коде как SVG | ваши | 0 |
| Анимированный фон, эффекты | собственный код на canvas | ваши | 0 |
| Фото, резюме | ваши | ваши | 0 |
| Картинка-превью `og.png` | сгенерирована скриптом | ваша | 0 |
| Библиотеки, шаблоны, стоки | **не используются** | — | 0 |

Что может стоить денег **потом**, если захотите:

* **Домен** вида `torogeldiev.dev` — 10–20 $ в год. Без него сайт живёт на бесплатном
  адресе GitHub Pages или Netlify.
* **Хостинг** — бесплатно на GitHub Pages / Netlify / Vercel, платить не нужно.
* **Formspree** для формы — бесплатно до 50 писем в месяц.
